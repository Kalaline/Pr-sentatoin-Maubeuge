# Éco Vert, découverte de Maubeuge

Site web réalisé dans le cadre de la SAE du BUT Informatique (IUT de Maubeuge). Il présente deux organisations de Maubeuge, le **Zoo de Maubeuge** et le supermarché **Match**, à travers 5 onglets.

## Contenu du site

- Une page d'accueil avec la navigation entre les 5 onglets
- Une page par onglet :
  - Onglet 1 : [Présentation]
  - Onglet 2 : [Démarche]
  - Onglet 3 : [Démarche]
  - Onglet 4 : [Charte]
  - Onglet 5 : [Présentation interactive]
- Un thème visuel vert forêt avec une touche d'orange

## Technologies utilisées

- HTML
- CSS (feuille de style commune à tous les onglets + une feuille pour l'accueil)
- JavaScript (animations et interactions)

## Structure du projet

| Fichier / dossier | Rôle |
|---|---|
| `index.html` | Page d'accueil |
| `style.css` | Style de la page d'accueil |
| `Style_commun.css` | Style partagé par tous les onglets (en-tête, logos) |
| `derouler` | [Comment on est parvenu à ce résultat] |
| `iut.png`, `iut2.png` | Logos |
| `onglet1/` à `onglet5/` | Pages des 5 onglets |
